Une valeur directement encodée dans une instruction est appelée valeur immédiate. Avec [color=#e49f44]Symphony[/color], nous pouvons remplacer l'argument B par une valeur immédiate dans n'importe quelle instruction. Cela se fait en positionnant le quatrième bit à 1 et en codant la valeur dans les deux derniers octets comme suit:

 [color=#ff9800]M[/color]  = Mode
 [color=#ff6680]O[/color]  = Opcode
[color=#9966ff]0[/color]/[color=#9966ff]1[/color] = Mode immédiat
 [color=#ffe666]D[/color]  = Registre de destination
 [color=#66ff99]A[/color]  = Argument A
 [color=#66ccff]B[/color]  = Argument B (éventuellement une valeur immédiate)
 [color=#bbbbbb]0[/color]  = Inutilisé / zero

Encodage de l'instruction si l'argument B n'est pas une valeur immédiate:
[color=#bbbbbb]0[/color][color=#ff9800]MM[/color][color=#9966ff]0[/color][color=#ff6680]OOOO[/color] [color=#ffe666]DDDD[/color][color=#66ff99]AAAA[/color] [color=#bbbbbb]0000[/color][color=#66ccff]BBBB[/color] [color=#bbbbbb]00000000[/color]
