0  nop       Ничего не делать
1  in        Ввод
2  out       Вывод
3  keyboard  Прочитать значение клавиатуры
4  screen    Установить параметры экрана
5  time_0    Прочитать младшие 32 бита времени
6  time_1    Прочитать старшие 32 бита времени
7  counter   Прочитать значение счётчика


Экран может интерпретировать байты в подключённом к нему ОЗУ множеством способов (см. руководство). У экрана есть входы «Enable», «Setting index» и «Value» — именно так происходит взаимодействие с внутренними регистрами экрана (также описано в руководстве).
При выполнении инструкции screen регистр экрана, указанный аргументом A, должен получить значение аргумента B (которое может быть непосредственным значением или браться из регистра).

Компонент Time выводит время в наносекундах с 1 января 1970 года (эпоха Unix) как 64-битное число. Поскольку архитектура работает только с 32 битами, значение разделено на две части, которые можно прочитать отдельно. Однако объединение значений времени с разных тактов может дать значения из будущего или прошлого из-за переполнения. Чтобы избежать этого, мы читаем таймер только при выполнении «time_0» и сохраняем результат, чтобы «time_1» мог прочитать его позже. Это значит, что «time_1» должен быть 0, если «time_0» ещё не выполнялся.

Счётчик относится к пользовательскому компоненту, который определяет смещение, с которого ассемблер читает код. Нужно прочитать текущее смещение.

Значение клавиатуры — это комбинация выходов «Key Down» и «Key Value» следующим образом:

D = Key Down
V = Key Value

0000000D VVVVVVVV
`),
