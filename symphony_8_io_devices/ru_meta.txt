    (mentor_left, `До сих пор в режиме Ввод-вывод было только 3 инструкции, но теперь пришло время добавить ещё несколько. Вот полный список опкодов инструкций Ввод-вывод:

0  nop       Ничего не делать
1  in        Ввод
2  out       Вывод
3  keyboard  Прочитать значение клавиатуры
4  screen    Установить параметры экрана
5  time_0    Прочитать младшие 32 бита времени
6  time_1    Прочитать старшие 32 бита времени
7  counter   Прочитать значение счётчика


Экран может интерпретировать байты в подключённом к нему ОЗУ множеством способов (см. руководство). У экрана есть входы «Разрешить», «Установка индекса» и «Значение» — именно так происходит взаимодействие с внутренними регистрами экрана (также описано в руководстве).
При выполнении инструкции screen регистр экрана, указанный аргументом A, должен получить значение аргумента B (которое может быть непосредственным значением или браться из регистра).

Компонент Time выводит время в наносекундах с 1 января 1970 года (эпоха Unix) как 64-битное число. Поскольку архитектура работает только с 32 битами, значение делится на две части, которые можно прочитать отдельно. Однако объединение значений времени с разных тактов может дать неверные значения из-за переполнения. Чтобы избежать этого, таймер обновляется только при выполнении «time_0» сохраняя значение «time_1» во временном буфере. 

Инструкция counter относится к пользовательскому компоненту, который определяет смещение, с которого ассемблер читает код. Нужно прочитать текущее смещение.

Значение клавиатуры — это комбинация выходов «Клавиша Нажата» и «Код Клавиши» следующим образом:

D = Клавиша Нажата
V = Код Клавиши

0000000D VVVVVVVV
`),
